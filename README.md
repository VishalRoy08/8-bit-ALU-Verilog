# 8-bit Arithmetic Logic Unit (ALU) using Verilog HDL

An 8-bit Arithmetic Logic Unit (ALU) designed and implemented in **Verilog HDL** and verified using **Xilinx Vivado**. This project demonstrates the implementation of fundamental arithmetic, logical, and shift operations that form the computational core of digital processors.

---

## Project Overview

The ALU performs operations on two 8-bit operands based on a 3-bit opcode. The design is purely combinational and produces a 16-bit output to accommodate multiplication results.

This project was developed to strengthen understanding of:
- Combinational digital logic
- Verilog HDL design
- FPGA design workflow
- Functional verification using testbenches
- RTL design and simulation in Xilinx Vivado

---

## Features

- 8-bit input operands
- 3-bit operation selector (Opcode)
- 16-bit output
- Fully synthesizable Verilog code
- Behavioral simulation using Vivado
- Simple and modular design

---

## Supported Operations

| Opcode | Operation |
|:------:|-----------|
| `000` | Addition (`A + B`) |
| `001` | Subtraction (`A - B`) |
| `010` | Multiplication (`A × B`) |
| `011` | Logical Right Shift (`A >> B`) |
| `100` | Logical Left Shift (`A << B`) |
| `101` | Bitwise AND |
| `110` | Bitwise OR |
| `111` | Bitwise XOR |

## How to Use

1. Clone this repository:
   ```bash
   git clone https://github.com/VishalRoy08/8-bit-ALU-Verilog.git
   ```
2. Open Xilinx Vivado.
3. Create a new Verilog project.
4. Add the files from the `src/` and `testbench/` directories.
5. Set `ALU_8Bit_tb.v` as the simulation top module.
6. Run **Behavioral Simulation** to verify the ALU operations.
